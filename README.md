# JAEDONGLAB Privacy Hub

JAEDONGLAB 앱별 개인정보처리방침 공개용 GitHub Pages 저장소입니다.

## 구조
- `/` : 개인정보처리방침 허브
- `/app001/` : APP-001 사진 속 글자찾기

향후 APP-002, APP-003 ... 을 동일한 방식으로 추가합니다.

## GitHub Pages 설정
Repository Settings → Pages → Build and deployment → Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

예상 URL:
`https://goagdaddy-cmyk.github.io/jaedonglab-privacy/`
